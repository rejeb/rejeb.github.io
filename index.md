## Dataform Plugin for IntelliJ

**Dataform Plugin for IntelliJ** brings full language support for
[Google Cloud Dataform](https://cloud.google.com/dataform) projects to IntelliJ IDEA, so you can
write, navigate, run and debug SQLX pipelines without leaving the IDE: SQLX highlighting and
completion, BigQuery SQL support, compiled query preview, data lineage, unit tests, and Dataform
workspace management.

The plugin asks you to sign in with Google only to interact with your Dataform repositories, run
Dataform workflow actions, and execute queries in BigQuery on your behalf. Your credentials stay
on your computer.
