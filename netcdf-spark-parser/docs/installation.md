## Requirements

- Java 11 or later.
- Apache Spark 3.5.x.
- Scala 2.12 or 2.13.

## Add the dependency

```scala
libraryDependencies += "io.github.rejeb" %% "netcdf-spark-parser" % "1.0.0"
```
